Sobre os dados: ficam apenas na memória deste navegador — nada é enviado a um servidor. Este cubo lê planilhas importadas (XLSX/XLS/CSV); conexão direta a um banco de dados SQL externo não é possível aqui porque o ambiente do artefato bloqueia requisições de rede para bancos de dados. Se precisar de conexão viva a um banco, isso exige um backend real (ex.: Claude Code com um serviço próprio, ou exportar o resultado da consulta SQL para planilha e importar aqui).
